# Flores y Corazones - Animated Flower and Heart Scene

## Project Overview
A beautiful animated scene featuring growing flowers, floating hearts, and "Ilybaby" text bubbles. This is a pure HTML/CSS/JavaScript project with complex CSS animations.

## Architecture
- **index.html**: Main structure with flower elements, bubbles, and animated components
- **style.css**: Complex animations and styling for all visual elements
- **script.js**: Minimal JavaScript to remove container class on page load

## Key Features
- Animated growing flowers with petals and stems
- Floating heart bubbles with SVG graphics
- "Ilybaby" text bubbles that float similar to hearts
- Complex CSS animations with different timing and delays
- Night sky background with gradient effects

## Animation System
- Uses CSS transform animations with various delays
- Multiple animation classes for different movement patterns
- Flowers grow in sequence with staggered timing
- Hearts and text bubbles float across screen with different paths

## Styling Notes
- Dark theme with night sky background
- Glowing effects on text and elements
- Responsive design using vmin units
- Complex layering with z-index for depth

## Development Notes
- All animations are pure CSS
- No external dependencies
- Optimized for modern browsers
- Performance-focused with hardware acceleration
